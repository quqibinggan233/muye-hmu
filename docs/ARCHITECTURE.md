# 牧野生活（HMU）架构设计文档

> **项目定位**：面向**河南牧业经济学院（HMU）**学生的 Android 校园聚合客户端（优先打通**龙子湖校区**，架构预留英才 / 北林多校区扩展配置；个人自用与小范围试用稳定后开源推广）。
> **技术底座**：基于 MIT 开源项目 [`f3ngka0/youwu`](https://github.com/f3ngka0/youwu) 二次开发，彻底移除 Python / Chaquopy 运行时，采用**全链路纯 Kotlin + Jetpack Compose + Material 3 + 液态玻璃（`Kyant0/backdrop`）**。

---

## 1. 产品与架构核心原则

1. **包名与品牌**：
   - 应用名：**牧野生活（HMU）**
   - Android `applicationId`：`com.hmu.muye`（内部源码维持 `com.fengkao.timetable` 基础命名空间 + `com.hmu.muye.*` 新增扩展包）
   - 视觉语言：延续 `youwu` 浅色/深色极简灰白画布 + 品牌蓝 `#174B8E` / `#4B8CE8` + 液态玻璃浮动胶囊底栏
2. **零自建后端，全本机加密存储**：
   - 所有账号密码、Session Cookie、消费与课表数据只保存在用户手机本地。
   - 凭据使用 **Android Keystore + AES-GCM** 加密存储（`Crypto`），网络请求直连学校与服务商网关，绝不经第三方中转服务器。
3. **安全与合规红线**：
   - **不自动绕过任何验证码**：遇到图形验证码、滑块或统一身份认证校验时，统一由用户本人通过内置界面 / WebView 手动完成。
   - **设备启动/扣费禁重试 + 防误触冷却**：喝水、吹风等涉及状态变更或扣费的控制请求均禁止 OkHttp `retryOnConnectionFailure`，超时时提示确认设备状态，保留 10 秒控制冷却。
   - **敏感权限克制**：快递聚合默认采用「通知栏监听 + 剪贴板识别」；`READ_SMS` 仅作为用户主动点击「扫描历史快递短信」时的可选权限，不在冷启动自动弹窗申请。
   - **校园实际规则**：河南牧业经济学院宿舍**不收取电费**，因此全应用**不包含任何宿舍电费查询或扣费 UI**。

## 2. 四栏信息架构（Bottom Navigation）

| Tab | 名称 | 核心内容 |
| --- | --- | --- |
| `0` | **课程** | 时段问候语 + 郑州龙子湖实时天气（Open-Meteo 免 Key + 本机 30 分钟缓存）<br/>顶部三态聚合条（下一节课 / 学习通最近待办 / 待取快递计数）<br/>周课表网格 ↔ 今日日程时间线切换 + 课前 10 分钟 / 上课时刻提醒开关<br/>画布拖拽排课 + 课程笔记（含图片与精确闹钟）+ 2×2 / 4×2 桌面小组件 |
| `1` | **学习** | 子分页：`学习通`（通知中心：待办 / 课表异动 / 通知原文 + 作业详情）<br/>`成绩`（超星教务 `hnuahe.jw.chaoxing.com` WebView 登录 + 学期筛选 + GPA/加权均分 + 对比缓存高亮「新出成绩」）<br/>`考试`（考试安排缓存与手动刷新 + 考试便签）<br/>`空教室`（教学楼/节次筛选，Phase 2 接入实时空教室接口）<br/>`图书馆`（微信公众号预约入口 / 可选 H5 直开） |
| `2` | **生活** | **采用方案 A（一屏分层宫格，无电费）**：<br/>• 顶栏：`HMU · 龙子湖校区` / `牧野生活` + 龙子湖校园网 Portal 认证状态胶囊<br/>• 易校园一卡通余额条（含低余额阈值本地提醒）<br/>• 动态待取快递卡（有件展示取件码/驿站/已取归档，无件自动折叠；右上角「淘宝身份码」「拼多多身份码」「粘贴/扫短信」）<br/>• 2×2 核心设备瓷砖：<br/>　1. **喝水（慧生活 798）**：一键直连启动 + 设备管理（参考 `Oasis-App` 拓展余额/订单）<br/>　2. **洗澡用水码（易校园）**：展示与刷新 6 位洗澡用水码（无需 BLE 蓝牙）<br/>　3. **吹风机（宿舍 U 净 + 浴室合肥海鸟）**：U 净原生查空闲与启动/直拉支付；海鸟内置扫码 + 常用吹风机扫码链接收藏<br/>　4. **洗衣机（乐仔生活）**：一期快捷入口，Phase 3 攻克空闲机位与剩余时间查询<br/>• 底部「校内速查与快捷入口」（河牧校历作息、龙子湖电话/地点速查、图书馆、自定义快捷方式） |
| `3` | **我的** | 学生身份卡、教务/学习通/喝水/易校园/U净/校园网独立账户管理、学期作息设置、课程隐藏与洞察统计、主题与更新 |

```text
    ├── data/
    │   ├── weather/                # 郑州龙子湖实时天气（Open-Meteo + 缓存）
    │   ├── jw/                     # 超星教务（hnuahe.jw.chaoxing.com）WebView 登录与原生解析

    │   └── campus/                 # 易校园用水码&余额 / 校园网 Portal / 海鸟书签 / 校历速查静态库
    └── ui/
        ├── study/                  # 「学习」Tab（学习通 / 成绩 GPA / 考试便签 / 空教室 / 图书馆）
        └── life/                   # 「生活」Tab（方案 A 一屏宫格，无电费）
```

## 5. 三阶段实施路线图

- **Phase 1（当前阶段 · 零抓包可编译运行 MVP）**：
  - 配置本机命令行 Android SDK；彻底清除 Chaquopy / Python 运行时。
  - 完成 4 Tab 液态玻璃框架、`课程`（郑州天气 + 日程切换 + 上课提醒）、`学习`（学习通 + 教务 WebView 登录底座 + GPA/考试便签 UI）、`生活`（方案 A 无电费宫格 + 798 + 快递通知/短信/身份码 + 海鸟扫码书签 + 校内速查）。
- **Phase 2（接口实采与原生打通）**：
  - 按 [`API_CAPTURE_GUIDE.md`](API_CAPTURE_GUIDE.md) 采集：超星教务 XHR 路由、龙子湖校园网 Portal、易校园用水码与一卡通余额、慧生活 798 `water.properties`、U 净吹风机接口。
  - 打通真实数据自动解析与刷新。
- **Phase 3（深度体验与开源分发）**：
  - 乐仔生活洗衣机空闲余时监控、内置 WebView 淘/拼/京包裹聚合（不挑安卓品牌）、英才 / 北林校区参数切换、完善签名发布与 GitHub 开源；远期再按需评估 Flutter / KMP iOS 版本。
